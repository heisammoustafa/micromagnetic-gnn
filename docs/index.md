# Micromagnetic GNN

Graph Neural Networks for predicting micromagnetic properties of polycrystalline grain structures.

## Quick Start

Install the package in development mode:

```bash
pip install -e ".[dev]"
```

Run tests:

```bash
pytest
```

Build documentation:

```bash
cd docs
make html
```
